# بصيرة 📱 (نسخة أندرويد)

مساعد ذكاء صناعي يشتغل **بالكامل على التلفون**، بدون حاسبة وبدون نت (إلا إذا تريد يبحث).

## التنصيب
1. افتح صفحة **Releases** بهالمستودع ونزّل `Basira.apk`.
2. نصّبه (إذا طلب، اسمح بالتنصيب من مصادر غير معروفة).
3. افتح التطبيق، فيوديك لقسم **النماذج**. نزّل **Qwen3 4B** (2.4GB، يحتاج نت وكت التنزيل بس).
4. بعدها يشتغل بدون نت.

## الميزات
- 💬 محادثات تنحفظ (اضغط مطولاً على المحادثة لتغيير اسمها)
- 🌐 بحث بالنت: يقرا الصفحات ويحفظها بذاكرته ويذكر المصادر
- 🧠 المعرفة: يتعلم من رابط أو موضوع، وتحفظ له تجاربك ويرجعلها
- 📦 النماذج: تنزيل، أو استيراد أي ملف `.gguf`
- ⚙ الإعدادات: الاسم، والشخصية، والإبداع، وحجم الذاكرة

## التقنية
Kotlin + Jetpack Compose، والمحرك هو [llama.cpp](https://github.com/ggml-org/llama.cpp) عن طريق JNI. ملف APK يتبنى تلقائياً بـ GitHub Actions مع كل تحديث.
